# Changelog

## 2.0.0 — 2026-09-30

- Rebuilt the console prototype as Arduino Mission Control, a JavaFX desktop application.
- Added automatic serial-port discovery, configurable baud rate and line endings.
- Added live multi-channel telemetry charts, a bidirectional terminal, quick commands and demo mode.
- Added automatic private CSV session logs and standard application-data storage.
- Added English/German help and a compatible Arduino demonstration sketch.
- Added bundled-runtime packages for Windows, Linux, macOS Intel and Apple Silicon.
- Added parser tests and packaged-runtime smoke tests.
- Removed committed IDE state and sample telemetry logs.
